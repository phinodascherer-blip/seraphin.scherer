# Persönliche Website - Seraphin Scherer

Die Website ist absichtlich einfach aufgebaut und benötigt keine Installation:

1. `index.html` doppelklicken, um sie im Browser zu öffnen.
2. Zum Ändern von Texten oder Kontaktdaten `index.html` mit einem Editor wie Visual Studio Code öffnen.
3. Änderungen speichern und die Browser-Seite neu laden.

## LinkedIn und Instagram

Die beiden Profil-Links sind bereits eingebunden. Falls sie sich später ändern, lassen sie sich ganz oben in `script.js` bei `socialLinks` ersetzen.

## Datenschutz

Die Seite enthält nur die ausdrücklich gewünschten, berufsbezogenen Kontaktmöglichkeiten. Die genaue Wohnanschrift, das Geburtsdatum, politische Zugehörigkeit, religiöse Details sowie Gesundheitsinformationen aus den Bewerbungsunterlagen wurden bewusst nicht veröffentlicht.

Vor dem Online-Stellen sollte die Telefonnummer noch einmal geprüft werden. Für noch mehr Privatsphäre kann sie in `index.html` im Kontaktbereich entfernt werden; die E-Mail-Adresse reicht für professionelles Networking in vielen Fällen aus.

Das FDP-Element nutzt die aktuelle Logo-Abbildung direkt aus dem offiziellen Corporate-Design-Bereich der FDP. Damit diese jederzeit korrekt und aktuell bleibt, wird sie erst beim Aufruf der Website geladen.

## Online stellen

Als nächster einfacher Schritt eignet sich GitHub Pages, Netlify oder Vercel. Erst nach dem Hochladen ist die Seite öffentlich erreichbar.
